# Insta Toolbox 4.5.0

Mutual Checker failed with "Open @you's profile" or an
HTTP 404 whenever it was started away from the profile being checked.

Instagram now answers both account lookups the checker used with HTTP 404,
for signed-in and signed-out tabs alike. The follower list route still works.
Version 4.5.0 checks your own account through that list route again. It binds
your numeric account ID only when Instagram's server-rendered viewer record and
app identity agree with the signed-in account shown in Instagram's navigation.
Started on your profile, the visible totals confirm completeness. Started
elsewhere, both lists are read but stay labelled partial, with a prompt to run
again from your profile to confirm the totals.

A tab with no signed-in account now says so instead of reporting a changed
account. Other accounts still use the native list on their open profile.
Nothing new is requested, stored or sent.

DM Unsend recognizes your messages again. Instagram now marks the side of
each message differently (`flow-end` for yours, `flow-start` for received),
and the ownership check only knew the older values, so an All-messages
Unsend scrolled up through the chat hunting for a message it could
recognize before its first removal. All other ownership rules are unchanged.

DM Unsend, reaction cleanup and Ghost Mode otherwise keep the 4.3.9 code,
the last version with a verified live removal. The 4.3.10 discovery-recovery
change is withdrawn. Restore found
conversations is no longer offered.

Validated live on November 27, 2026 in a signed-in browser: own-account
checks from the profile and from other pages, Stop, other accounts, manual
list capture, Insights, Presence review and an approved All-messages Unsend.
Extension, desktop and web/PWA downloads remain on hold at 4.3.1.
