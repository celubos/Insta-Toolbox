# Insta Toolbox 4.3.10

Development candidate. Instagram can reload the page while Find conversations
is opening chats. Previously this erased the list. The toolbox now saves
bounded observations before the next chat and offers Restore found conversations.

Restored results are partial, expire at the original deadline and show names
from earlier observations. Choose exact conversations and review again before
cleanup. Old selections, approvals and native message evidence are discarded.
Managed worker tabs reverify the account, thread and sent messages. Stop also
cancels a restoration still waiting on storage.

Native lists, Presence controls, serial-tab history, Insights and one approved
message removal passed in installed 4.3.9. Ghost reload recovery and execution
remain required in this candidate. No official release is recorded. Protected
promotion access is unavailable; stable downloads remain at 4.3.1.
