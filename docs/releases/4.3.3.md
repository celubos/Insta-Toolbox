# Insta Toolbox 4.3.3

- Restore profile comparisons through native Followers and Following lists
  when both account lookup routes are unavailable. Reverify the owner, account,
  dialog and ending counts throughout the read.
- Keep interrupted native reads separate from the saved comparison and offer
  an explicit partial download.
- Read selected Growth seed profiles through normal profile links and explicit
  native-list reads. Keep an expiring read-only draft across navigation, show
  each source and its completeness, and require fresh action reviews.
- Keep native account verification usable behind the exact verified list
  backdrop while preserving strict ordinary account detection.

Live like me continues only selected activities for the chosen duration. It
does not learn personal tastes or run with the browser closed. Instagram
restrictions, ambiguous targets and uncertain results stop the relevant action.

Tampermonkey is the active update channel. Publication is limited to its tested
userscript, SBOM and checksums. Existing extension, desktop and web/PWA downloads
and local data remain on hold at 4.3.1; all package checks remain required. The
Pages gate prevents later web packages from replacing the held deployment.

Consult the [acceptance record](../acceptance/4.3.3.md) and
[compatibility notes](../compatibility/4.3.3.md) for the tested scope and limits.
This remains a development candidate: installation, authenticated acceptance
and final-source CI are pending.
