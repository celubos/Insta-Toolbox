# Insta Toolbox 4.3.2

- Verify the signed-in account from navigation rather than unrelated feed or
  story avatars.
- Add an existing-route account lookup fallback for unavailable search requests.
  Exact username and numeric identity checks still apply; authentication,
  restriction and rate-limit responses stop the request.
- Show manual-list progress and a dedicated Stop control. Keep captured rows
  available after cancellation, and require a fresh matching native count
  before reporting a complete list.
- Preserve Live like me selections, duration and optional breaks. Keep verified
  progress and uncertain results visible when a run pauses or stops.
- Keep growth actions bound to the reviewed account and targets. Reconcile a
  pending action before allowing another attempt.
- Recognize current profile counter controls and profile-prefixed post links.
  Use visible carousel markers within each post link; leave unproven media and
  dates unknown. Keep partial comparisons and sampled insights clearly labelled.
- Improve narrow-panel controls, empty-state guidance and contrast.
- List each selected conversation in the Ghost Mode confirmation.

Tampermonkey is the active update channel. Publication is limited to the tested
userscript, its SBOM and checksums. Chrome extension, Windows/macOS desktop and
web/PWA downloads remain on hold at 4.3.1; their existing downloads and local data
remain available.

The Pages deployment gate also retains the held PWA at 4.3.1. CI continues to
build and verify the web package without deploying later versions.

Live like me repeats the activities selected for the loaded tab. It does not
learn preferences or run with the browser closed. Instagram restrictions and
ambiguous targets stop the relevant action instead of guessing. See the
[acceptance record](../acceptance/4.3.2.md) and
[compatibility notes](../compatibility/4.3.2.md) for the recorded scope.
