# 4.3.3 acceptance

Historical development candidate; no official release. Assembly, the local
checks below and all eight candidate CI checks passed. Installed-build testing
found a native-list readiness failure, so authenticated acceptance did not pass.
The repair is tracked in [4.3.4 acceptance](./4.3.4.md).

## Scope

Authenticated testing of the preceding candidate found that both existing
account lookup routes returned HTTP 404 while native profile lists remained
available. This version adds an explicit native-list fallback after the exact
404/410 lookup-retirement chain. Authentication, restriction, rate-limit,
identity, parsing and cancellation failures do not authorize that fallback.

Native reading requires the exact requested open profile, its unique owner
header and count controls, and the exact newly opened list dialog. Account
navigation is reverified throughout the read, including its rendered backdrop.
Replacement dialogs, changed accounts or routes, hidden evidence and unproven
ending counts cannot establish a complete result. Native captures retain their
own provenance and never invent a numeric account ID or API receipt.

Interrupted primary reads preserve the saved comparison. Scoped partial rows
remain available separately for download. A normal bounded result can replace
the pair only with its actual per-list verification and completeness.

Growth retains an expiring read-only draft for one to three selected seeds when
lookups are unavailable. The person opens each named profile and explicitly
reads its native lists. Drafts bind the actor, captured Following snapshot,
selection, profile, source, time and list verification; a read does not grant
Follow or Unfollow authority. Existing fresh target reviews, account checks,
native action verification and campaign checkpoints remain required.

## Evidence boundary

The preceding 4.3.2 candidate passed its source, browser, sandbox, rendering and
GitHub checks. Authenticated observation verified selected Presence actions,
Pause/Resume, a persisted native Like, sampled Insights exports and manual scan
progress, Stop and list-count agreement. Its lookup and Growth failures are the
reason for this repair. Those observations do not validate the new code.

Synthetic fixtures are an independent interaction model. They do not establish
one-to-one Instagram backend equivalence or authenticated mutation outcomes.
Private accounts, messages, identifiers, captures and exports remain outside the
repository.
