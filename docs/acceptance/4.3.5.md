# 4.3.5 acceptance

Development candidate. Assembly, the complete source suite, package safety and
reviewed rendering passed. Production native browser, background and sandbox
acceptance, installation, authenticated acceptance and exact-candidate CI remain
pending. No official release is recorded here.

## Scope

The preceding 4.3.4 candidate passed automated and candidate CI gates but failed
native comparison acceptance. A pagination loader clipped below the visible
list was treated as initial loading despite available rows and a scroll
container. The bounded timeout retained partial rows and preserved the saved
comparison, but it could not finish the requested comparison.

This repair starts native collection when verified rows and their actual
scroll container are available. Loader visibility considers CSS, dialog bounds,
overflow clipping and the viewport. A mounted trailing loader cannot stall
startup, while a genuinely visible loader still prevents unproven completion.
Exact empty lists and fixed lists without a scroller retain their readiness
safeguards. Completion still requires fresh, exact ending totals.

Stop and the bounded loading timeout retain observed partial rows separately
and preserve the saved comparison. The timeout cannot open the next list.
Manual scan defaults, exact owner/account/dialog checks and native provenance
remain unchanged.

Growth drafts now retain the native loading-timeout reason as partial evidence.
That does not create a candidate, grant action authority or turn native rows
into authenticated API evidence. Existing expiry, actor binding and fresh
action-specific reviews continue to apply.
