# 4.3.9 acceptance

Development candidate; official publication remains held.

## Native list performance repair

Installed 4.3.8 exposed unresponsive tabs during both the primary mutual check
and a manually opened Following scan. The account viewer treated dialog
profile avatars as possible account navigation and repeatedly searched their
shared ancestors. A 198-row reproduction performed 396 list rescans and
79,002 geometry reads without establishing account proof.

The viewer now excludes links inside native dialogs before geometry and
ancestor searches. Actual navigation and explicitly scoped native-list
backdrop proof keep their existing validation. The same reproduction avoids
those rescans without promoting an unverified account. The two new behavioral
regressions and 222 neighboring native, identity and request checks passed.
This identifies a source performance defect; installed retesting must establish
whether it resolves the observed stalls.
