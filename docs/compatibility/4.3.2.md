# Insta Toolbox 4.3.2 compatibility

This userscript development candidate retains the existing storage namespace,
release update channel and userscript grants. Final authenticated acceptance is
pending; supported fixture behavior is not proof of current Instagram outcomes.

| Tool | Supported scope | Boundary |
| --- | --- | --- |
| Mutual Checker | Exact account lookup, comparison, cancellable manual list capture and exports | Search fallback uses only the existing profile GET route; missing records and unproven final counts remain partial. |
| Insights | Reports from loaded profile and post data | A visible sample does not establish a complete account history. |
| Presence | Selected activities in a finite session or for the chosen Live like me duration | Requires the current account, a loaded tab and fresh confirmation; no preference learning. |
| Growth | Reviewed follow targets and later reviewed due unfollows | Saved campaigns do not authorize unattended actions. |
| DM Unsend and own reactions | Reviewed sent-message scope and independently verified own reactions | Received messages remain; uncertain outcomes are reported separately. |
| Ghost Mode | Reviewed available conversations processed in managed tab groups | Discovery can be partial; every worker retains account and thread checks. |

Chrome 138 and newer require Tampermonkey's **Allow User Scripts** permission
in addition to the script's enabled switch. See the
[official permission instructions](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)
and [Chrome's user-script documentation](https://developer.chrome.com/docs/extensions/reference/api/userScripts#chrome_versions_138_and_newer_allow_user_scripts_toggle).
Managed workers also require the userscript-manager tab/storage APIs and Web
Locks. Sleep, tab discard, session expiry and restrictions can interrupt work.

The Chrome extension, desktop and web/PWA packages remain on hold at their
published 4.3.1 downloads. Their [compatibility record](4.3.1.md) remains
separate. See [4.3.2 acceptance](../acceptance/4.3.2.md) before publication.
