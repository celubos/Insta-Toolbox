# Insta Toolbox 4.3.3 compatibility

This development candidate preserves the existing userscript identity, storage
namespace, grants and stable update URL. Live testing found that the primary
native checker could advance before the first list loaded. Authenticated
acceptance did not pass, and no official release was published. See the
[4.3.4 candidate](./4.3.4.md) for the readiness repair.

| Tool | Supported scope | Boundary |
| --- | --- | --- |
| Mutual Checker | Existing lookup routes and exact native profile-list fallback | Native fallback requires the requested profile to be open; ambiguous or unproven lists remain partial. |
| Growth | Existing discovery plus explicit reads of selected native seed profiles | Read-only drafts expire and bind actor, Following evidence, selection and source. No automatic Follow or future Unfollow is authorized. |
| Insights | Summaries and exports of loaded posts | Missing types and dates remain unknown; samples do not establish full account history. |
| Presence | Selected finite or timed activities with Pause and Stop | The tab must remain loaded; restrictions and uncertain outcomes stop the relevant action. |
| DM and Ghost Mode | Reviewed own-message and own-reaction scopes | Received messages remain; exact account/thread checks and verified removal are required. |

Native lists can make the rendered profile and account rail unavailable to
accessibility while their backdrop remains visible. Only the exact verified
native list context permits reading that backdrop; ordinary viewer detection
remains strict.

Opening a profile list and closing its exact dialog are guarded native read
operations. Account and message mutations retain the isolated live activator
and their existing action-specific reviews. Native list captures do not supply
authenticated API evidence to Presence.

Chrome 138 and newer require **Allow User Scripts**, separately from the script's
enabled switch. Managed workers require the existing userscript-manager APIs
and Web Locks. Sleep, discarded tabs, expired sessions and restrictions can
interrupt work.

The held extension, desktop and web/PWA downloads remain on 4.3.1. See
[acceptance](../acceptance/4.3.3.md) before publication.
