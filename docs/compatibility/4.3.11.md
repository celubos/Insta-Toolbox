# Insta Toolbox 4.3.11 compatibility

Development repair for the Mutual Checker HTTP 404 failure observed on
November 27, 2026.

## Observed Instagram behavior (2026-11-27, signed-in web session)

| Route | Result |
| --- | --- |
| `/api/v1/web/search/topsearch/` | HTTP 404, HTML page |
| `/api/v1/users/web_profile_info/` | HTTP 404, HTML page, for existing and missing usernames |
| `/api/v1/friendships/<id>/followers/` and `/following/` | HTTP 200 JSON with working pagination |

Instagram's HTML 404 page is marked `not-logged-in` in signed-in and
signed-out tabs alike, so that marker is not evidence of the session state.

No grants, endpoints, storage keys, public identity or stable installation
URLs change. The toolbox does not read cookies or request headers. Held
extension, desktop and web/PWA downloads remain at 4.3.1. Official release
requires all checks plus protected current-main promotion. See
[acceptance](../acceptance/4.3.11.md).
