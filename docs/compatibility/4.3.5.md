# Insta Toolbox 4.3.5 compatibility

This development candidate preserves userscript identity, grants, storage and
the stable update URL. Final-build source and full automated checks,
installation, authenticated acceptance and CI are pending.

| Tool | Scope | Boundary |
| --- | --- | --- |
| Mutual Checker | Existing lookup routes and exact native profile-list fallback | Rows with their actual scroll container can start collection despite a trailing loader. Visible loading and unverified ending totals cannot prove completion. |
| Growth | Explicit reads of selected native seed profiles | Loading-timeout evidence remains partial and cannot create candidates or authority. Draft expiry, actor binding and fresh reviews still apply. |
| Insights | Summaries and exports of loaded posts | Missing dates and media types remain unknown; samples are not full account history. |
| Live like me | Selected activities for a finite count or duration | The tab must remain loaded; restrictions and uncertain outcomes stop the relevant action. |
| DM and Ghost Mode | Reviewed own-message and own-reaction scopes | Exact account/thread checks, current authority and verified outcomes remain required. |

Loader visibility includes CSS, dialog bounds, overflow clipping and viewport
intersection. Exact empty-list and fixed-list safeguards, fresh counts, Stop,
the loading deadline and manual scan defaults remain unchanged. Native rows
retain list-dialog provenance and cannot supply authenticated Presence evidence.

Chrome 138 and newer require **Allow User Scripts**, separately from the
script's enabled switch. Managed workers require userscript-manager APIs and
Web Locks. Sleep, tab discard, session expiry and restrictions can interrupt
work.

Extension, desktop and web/PWA downloads remain on hold at 4.3.1. Consult
[acceptance](../acceptance/4.3.5.md) before publication.
