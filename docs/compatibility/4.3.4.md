# Insta Toolbox 4.3.4 compatibility

This development candidate preserves the userscript identity, grants, storage
namespace and stable update URL. Final-build automated checks, installation,
authenticated acceptance and CI are pending.

| Tool | Supported scope | Boundary |
| --- | --- | --- |
| Mutual Checker | Existing lookup routes and exact native profile-list fallback | Native reads wait for initial readiness. Timeout or Stop cannot establish completion or open the next list; saved comparisons remain unchanged. |
| Growth | Explicit reads of selected native seed profiles | Drafts expire and bind the actor, Following evidence, selection and source. Actions still require fresh reviews. |
| Insights | Summaries and exports of loaded posts | Missing dates and media types remain unknown; a sample is not full account history. |
| Live like me | Selected activities for a finite count or duration | The tab must remain loaded. Restrictions and uncertain outcomes stop the relevant action; configured expiry requires live verification. |
| DM and Ghost Mode | Reviewed own-message and own-reaction scopes | Exact account/thread checks, current authority and verified outcomes are required. |

The new readiness wait is bounded to 20 seconds and applies only to the native
fallback. Manual list scans keep their existing default timing. A verified
empty list still needs exact initial and ending totals. Native captures retain
their own provenance and do not supply authenticated API evidence to Presence.

Chrome 138 and newer require **Allow User Scripts**, separately from the
script's enabled switch. Managed workers require the userscript-manager APIs
and Web Locks. Sleep, discarded tabs, expired sessions and restrictions can
interrupt work.

Extension, desktop and web/PWA downloads remain on hold at 4.3.1. See
[acceptance](../acceptance/4.3.4.md) before publication.
